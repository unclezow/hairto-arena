# Leaderboard character portraits

Original artwork generated with the built-in imagegen tool, transparent background enabled. Original PNG alpha preserved. Reference screenshots guide the leaderboard composition only; no third-party game artwork is used.

These static portraits are decorative archetypes for podium cards, not claims about a ranked wallet's equipped character. Ranking, score and qualification come from the API; sample players are explicitly marked DEMO.
