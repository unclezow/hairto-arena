# Emerald Brawler lobby background

Generated with the built-in imagegen tool for Hairto Arena NEAR, not copied from another
game. The source PNG is preserved as `emerald-brawler-lobby-v1.png`; the lobby
uses `emerald-brawler-lobby-v1.webp` (WebP quality 90, no resizing).
Only the lobby backdrop and background lighting consume this asset. The arena,
characters, and popup/menu behavior are unchanged.

## Final prompt

Use case: stylized-concept. Asset type: production background only for a full-screen fantasy mobile arena game lobby, landscape 16:9, high resolution 2560x1440 if possible. Create original polished game-menu background art with the bold cheerful arcade energy of premium mobile brawler games, using Hairto Arena NEAR's emerald, jade green and teal identity. Absolutely NOT a scenic landscape, NOT realistic, NOT forest, no mountains, no clouds, no trees, no characters, no platforms, no text, no letters, no logo, no UI panels or buttons. Composition: clean saturated jade/emerald central field, soft luminous mint-green circular spotlight behind the central character position at 50% horizontal and 48% vertical, deeper emerald and ocean-teal toward outer corners. Several very broad subtle geometric radial light rays spreading outward, spacious restrained celebratory arcade atmosphere. An evenly spaced staggered all-over pattern of original very simple oversized angular shield silhouettes, small four-point heroic stars and crossed sword emblem silhouettes, only slightly darker or lighter than their local background, about 5 to 9 percent contrast, broad simple silhouettes that remain quietly visible behind UI. Pattern has consistent size and spacing and looks like beautifully art-directed game menu wallpaper; it is not an illustration of physical items. Faint clean horizontal gradient near lower quarter suggests a virtual stage without an actual ground plane or hard horizon. Mostly 2D graphic game art with soft smooth shading and subtle dimensional light, crisp bold color, matte finish, no paper grain, no photographic texture, no fine noise, no realistic stone. Keep center uncluttered for the existing 3D knight and the lower center uncluttered for existing battle buttons. Original symbols, do not reproduce any existing game's skull logo or characters. The image must look unmistakably like a premium playable game lobby backdrop.
