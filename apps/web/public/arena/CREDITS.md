# Hairto Arena NEAR — The Floating Grounds

## Fighters

Knight, Mage, Rogue, Rogue Hooded and Barbarian models and their animations are
by **Kay Lousberg / KayKit**, licensed **CC0 1.0 Universal**.
Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
The license is retained in `characters/LICENSE.txt`. Original embedded textures
and skeletal animations are preserved.

## Environment and effects

The floating island geometry, cloud density/sunlight volumes, combat effects,
round introduction artwork and synthesized introduction sounds are original
project assets. The cloud files store density and sunlight as RG8 volumes;
each 128 × 80 × 80 volume contains 1,638,400 bytes. The scene serves assets locally.
The current sky combines a CSS gradient with animated 3D clouds. The earlier
painted valley panorama is retained as an unused asset; its generation prompt
is in `environment/GENERATION.md`.

The round introduction uses original SVG filigree, a crossed-sword crest,
metallic text, ring ornament and ember animation. Character death animations
come from the KayKit pack. Brawlhalla was a visual reference only; no artwork
or assets from that game are included.
